# National Geographic — Telegram Mini App

Готовый статический Telegram Mini App с тёмной редакционной стилистикой, разделами, поиском, избранным и нижней навигацией.

## Что внутри
- Главная с hero-блоком
- Разделы: Природа, Животные, Океан, Путешествия, Космос, Фото дня
- Поиск
- Избранное с localStorage
- Нижнее меню
- Интеграция Telegram WebApp
- Ссылка на канал https://t.me/national2026geographic

## Важно
В демо используются публичные изображения Unsplash. Для рабочего проекта замените их на собственные изображения/медиа и подключите источник публикаций канала через свой backend.

## Запуск
1. Загрузите файлы на HTTPS-хостинг.
2. Создайте бота через @BotFather.
3. В BotFather настройте Main Mini App или Menu Button и укажите URL `https://ВАШ-ДОМЕН/`.
4. Откройте приложение через бота.

Telegram требует HTTPS для production Mini Apps. Документация:
https://core.telegram.org/bots/webapps
